# PENAFLOR-PROJECT-1 — Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS.

## Folder structure

- `index.html` — Main website page
- `styles/style.css` — Website styling and responsive layout
- `assets/profile-placeholder.svg` — Replace this with your own profile photo if desired

## Run locally

Open `index.html` in your web browser.

## Publish with GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

## Suggested development commits

Make a real change before each commit. Examples:

1. Initial portfolio website
2. Add navigation menu
3. Create hero section
4. Add about section
5. Add skills section
6. Add projects section
7. Add contact section
8. Improve visual styling
